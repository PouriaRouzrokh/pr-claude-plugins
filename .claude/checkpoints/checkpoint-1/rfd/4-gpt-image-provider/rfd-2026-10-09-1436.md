## Feature Request

### Original Request

"For image generation can you also add chatgpt image in addition to the nano banna pro 2.1? Depending on the use case either of these should be used. Because both of these are great and are good for different use cases."

### Clarified Requirements

- Add OpenAI's ChatGPT image models to `generate-image` alongside Nano Banana 2.1 and Pro.
- Route each request to the better model by use case, documented in SKILL.md.

### Out of Scope

- OpenAI Responses API multi-turn editing (refinement uses the edits endpoint instead).

## Context

Verified on 2026-10-09 against the OpenAI SDK (openai 3.27.0 types and docstrings) and developers.openai.com (`.md` pages):

- `gpt-image-2.5-sunburst`: "our most capable model"; editing precision. `gpt-image-2.5-flare`: fastest high-quality everyday model. `chatgpt-image-latest` is the *previous* ChatGPT model; OpenAI recommends Sunburst for API use. DALL-E 2/3 retired 2026-05-12.
- Images API: `background` transparent/opaque/auto (png/webp only), `quality` up to `xhigh`/`max` on 2.5, `n` 1-10, `output_format` png/jpeg/webp, custom `WIDTHxHEIGHT` (multiples of 16, ratio 1:3-3:1, 655,360-8,294,400 px, edge <= 3840), edits with up to 16 images and an alpha mask (applied to the first image), `input_fidelity` must be omitted on 2.x.
- Pricing is token-based (/1M image output, /1M image input, /1M text input); organization verification may be required.

## Implementation

- `generate_image.py` now has two backends behind one CLI. Aliases `gpt`/`chatgpt` (Sunburst) and `gpt-fast` (Flare); model IDs starting with `gpt-image`/`chatgpt-image` route to OpenAI. PEP 723 deps add `openai>=2,<4`; each SDK imports optionally.
- New GPT-only flags: `--background`, `--mask`, `--quality`, `-n`; `.webp` output. `-s 1K/2K/4K/auto/WxH` and `-a` translate to valid OpenAI sizes (standard sizes for 1:1, 3:2, 2:3 at 1K).
- Cross-provider validation: Google-only flags (`--search`, `--thinking`, `--continue`) and GPT-only flags fail early with guidance.
- After GPT calls the script prints token usage and an estimated cost; revised prompts are printed.
- SKILL.md: model table, a "Choosing a Model" routing table (transparency, masks, variations, exact sizes → GPT; search grounding, many references, extreme ratios, 4K, multi-turn, bulk → Nano Banana; dense text → Pro), and a bake-off recommendation for important assets.
- Docs, manifests (2.1.0), and CLAUDE.md test command updated.

## Testing

- 29 new offline tests (`tests/test_generate_image_openai.py`); full suite 75 passed. Sent parameters are checked against the SDK method signatures.
- Real OpenAI SDK with stubbed HTTP: `/v1/images/generations` JSON body (size 2560x1440, quality xhigh, transparent, webp) and `/v1/images/edits` multipart (`image[]`, `mask`).
- Headless Claude Code (Haiku): a transparent mascot request chose `-m gpt --background transparent`; a weather infographic chose Nano Banana with `--search`.
