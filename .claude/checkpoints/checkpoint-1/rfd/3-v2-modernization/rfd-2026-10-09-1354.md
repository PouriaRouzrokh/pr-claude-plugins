## Feature Request

### Original Request

"Take a look at what we already have in this folder and try to enhance all the different skills that we have here, including all the different image creation, web design and all these skills. These have been developed many months ago so probably newer versions or better techniques and better software and everything is available... I assume that we even have a lot more useful skills that you can search online and we can add here... debug everything so try to polish this repo as much as possible and enhance everything and push."

### Clarified Requirements

- Audit every command, skill, agent, and manifest for bugs against the current (October 2026) Claude Code plugin spec.
- Update each vendored skill to its current upstream version, with correct license attribution.
- Move the Gemini skills to current models and APIs and make them work from a plugin install.
- Add new skills that fit the toolkit and do not duplicate Claude Code built-ins.
- Verify everything, then commit and push.

### Out of Scope

- Renaming the marketplace (`pr-cloud-plugins`): existing installs depend on the name.
- Choosing a license for the plugin's original content.

## Context

### Research (four parallel agents, verified against primary sources)

- **Claude Code spec** (code.claude.com/docs): `commands/` is legacy; skills are slash-invocable; a command and a skill with the same name collide on `/pr:<name>`. `LS`, `NotebookRead`, `KillShell`, and `BashOutput` are no longer tool names. `${CLAUDE_SKILL_DIR}` substitutes a skill's absolute path in SKILL.md. `disable-model-invocation` exists for side-effecting skills.
- **Gemini API** (ai.google.dev, checked directly): `gemini-3.1-flash-image-preview` and `gemini-3-pro-image-preview` shut down 2026-06-25. Current: `gemini-nano-banana-2.1` (recommended), `gemini-3.1-flash-image`, `gemini-3-pro-image`, `gemini-3.1-flash-lite-image`. The Interactions API is Google's recommended interface. Text: `gemini-3.8-flash` (thinking levels low/medium/high). Video: Veo 3.1 previews shut down 2026-10-22; `gemini-omni-1.1-flash` replaces them. google-genai 2.29 requires Python 3.10+.
- **Upstreams**: impeccable restructured into a CLI-driven skill (v4.5.2); Anthropic's frontend-design rewritten twice; Vercel react-best-practices added 13 rules; tailwind-design-system moved to Tailwind v4; Agentation added an MCP server (3.1); softaworks writing skill had a one-word fix.
- **New skills scouted**: obra/superpowers (systematic-debugging, TDD, verification), addyosmani/web-quality-skills, Gemini Omni video; rejected duplicates of built-ins (`/code-review`, `/security-review`, `/simplify`, skill-creator, mcp-builder).

## Implementation

### Structure

- All 12 commands became skills (`pr/skills/<name>/SKILL.md`); `pr/commands/` removed. `commit-push` and `run-public` set `disable-model-invocation: true`.
- `generate-image-nb` renamed to `generate-image` (keeps `/pr:generate-image`).
- Version 2.0.0 in `plugin.json` and `marketplace.json`; plugin manifest gained homepage, repository, keywords.

### Gemini skills

- `generate-image/scripts/generate_image.py`: Interactions API; aliases `nb` (2.1, default), `pro`, `nb2`, `lite`; per-model validation of size, ratio, search, and thinking; `--continue <interaction_id>` multi-turn editing; up to 14 inputs; output MIME negotiated from the extension; no-overwrite paths; retries on 429/5xx; saves search-suggestion HTML for attribution.
- `generate-svg/scripts/generate_svg.py`: `gemini-3.8-flash` default, `pro` = `gemini-3.1-pro-preview`; XML validation with one automatic repair turn; sanitizes scripts, event handlers, and `javascript:` URLs; `-e` edit mode; `--preview` PNG via resvg-py; svgo via `npx --yes`.
- New `generate-video/scripts/generate_video.py`: Omni Flash text/image-to-video, first/last frames, upload-and-edit, extension, `--continue`, URI delivery for 1080p/4k.
- SKILL.md files rewritten around heredoc invocation, model tables, review-the-output steps, and limits. `references/prompting-guide.md` distilled from Google's current guide.

### Refreshed skills

- `frontend-design` (background agent): Anthropic's current skill as backbone, impeccable v4.5.2 references without CLI dependencies, 70 Vercel React rules, Tailwind v4 reference, NOTICE.md and Apache license text.
- `agentation`: upstream 3.1 flow (MCP mode, round-trip verification), generalized to any React 18+ app, PolyForm notice.
- `writing-clearly-and-concisely`: upstream fix, attribution for MIT and CC BY-SA content.
- `create-prd`: no hardcoded year in research queries.
- `mvp-dev`: RFD and summary templates moved to `references/rfd-template.md` (SKILL.md now 500 lines).

### New skills

- `systematic-debugging` and `test-driven-development` (adapted from obra/superpowers, MIT): Python/ML sections, proportional rigor, RFD integration, `find-polluter.sh` generalized to any test runner.
- `web-quality-audit` (background agent, adapted from addyosmani/web-quality-skills, MIT): Lighthouse 13 and axe runs with a JSON summarizer; verified against a real test page.
- Integrated into `feature-dev`, `mvp-dev`, `run-public`, and the ATLAS skills-by-phase table.

## Testing

- `tests/`: 46 offline pytest cases for the three Gemini scripts (fake clients; request dicts validated against the SDK's own pydantic models). All pass.
- Real google-genai 2.29 client with stubbed HTTP: confirmed request bodies for `/v1beta/interactions` and `models/gemini-3.8-flash:generateContent`, thought-image skipping, and thought-text exclusion.
- `uv run` PEP 723 path and the Python 3.9 error message verified.
- `claude plugin validate` passes for the plugin and the marketplace.
- Repo checker: YAML frontmatter parses, names match directories, descriptions ≤ 1024 chars, SKILL.md ≤ 500 lines, 141 relative links resolve.
- Headless Claude Code (`--plugin-dir`, Haiku): all 20 skills register; `/pr:generate-image` resolved `${CLAUDE_SKILL_DIR}`, used the heredoc form, and failed cleanly on the missing API key.
- Not tested: live Gemini calls (no API key on this machine). Model IDs and parameters were checked against Google's docs and the SDK types.

## Notes & Decisions

- Kept generateContent for SVG text generation (stable, fully supported) and used Interactions for image and video (required for current features).
- Did not expose Omni's `duration` field: it is undocumented.
- Kept a single Python implementation per script instead of parallel Python/JS versions.
- Marketplace owner email in `marketplace.json` left unchanged.
